# Contributing

Thank you for helping improve CSEExamTTY. Keep changes focused, include tests,
and run `ruff check src tests scripts`, `mypy src/csetty`, and `pytest -q` before
opening a pull request.

Contributions to Apache-licensed paths identified in `LICENSES.md` are submitted
under Apache-2.0 unless conspicuously marked otherwise and agreed by the project
owner. By submitting, you represent that you have the right to provide the
contribution under those terms.

The assessment trees `packs/**` and `question_bank/**` are CC BY-NC-ND 4.0.
Because that licence does not permit sharing adapted material, do not publish a
pull request that modifies or derives from those materials unless the copyright
owner has separately authorized that contribution. An entirely original
assessment proposal may first be discussed without including restricted files.

Never submit UNSW exam questions, course-site copies, student work, credentials,
real zPasswords, local attempt databases, submissions, reports, VSIX/Server
caches, DCC binaries, Debian archives, or locally built container images.
