# COMP1511-style Original Practice Paper A

Time allowed: 10 minutes reading time and 3 hours working time.  Total: 100 marks.

This is original CSEExamTTY material and is not a UNSW examination. During the
working period, run `1511 autotest qX` and submit with
`submit qX prac_qX.c`. Run `check` to list submitted questions. Autotesting does
not submit. Only the latest accepted local submission is used for the final
simulator report.

## Questions

1. **Linked-list hurdle, 12 marks:** count adjacent non-zero values whose signs differ.
2. **Array hurdle, 12 marks:** read a square array and sum its border once.
3. **Linked-list hurdle, 12 marks:** delete and free the first negative node.
4. **Array hurdle, 12 marks:** count interior cells larger than four orthogonal neighbours.
5. **5 marks:** repair the supplied signed-number classification program.
6. **5 marks:** repair the supplied natural-number summation program.
7. **5 marks:** swap two integers using pointer parameters.
8. **5 marks:** create a character list and count its digit nodes.
9. **11 marks:** find the longest run of equal characters in a non-empty string.
10. **11 marks:** report the most frequent lowercase letter, resolving ties alphabetically.
11. **10 marks:** implement `add`, `mul`, `print`, and `quit` accumulator commands.

Every answer must remain in its supplied `prac_qX.c` file. Use only standard C
libraries, do not launch external programs, and do not change required input or
output formats.
