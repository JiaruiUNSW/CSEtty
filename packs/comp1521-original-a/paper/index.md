# COMP1521-style Original Practice Paper A

Time allowed: 10 minutes reading time and 3 hours working time. Total: 100 marks.

This is original CSEExamTTY material, not a UNSW examination. Use
`1521 autotest qX`, submit with `submit qX FILE`, and list submitted questions
with either `check` or `1521 classrun -check`. Run `1521 classrun qX` to display
the latest submitted source for one question.

## Questions — 10 marks each

1. Rotate an unsigned 32-bit value right using C bit operations.
2. Translate two-input integer subtraction into MIPS.
3. Count logical lines using `open`, `read`, and `close` rather than stdio.
4. Sum the integers from one through `n` using a MIPS loop.
5. Count UTF-8 code points by identifying non-continuation bytes.
6. Count all set bits in a 32-bit MIPS register.
7. Fork a child, wait for it, and report its normal exit status.
8. Read five signed integers in MIPS and print their maximum.
9. Use exactly two POSIX threads to sum the range from one through `n`.
10. Transfer a range sum from one child through a robust POSIX pipe.

All programs must use the supplied filename and required language. Programs
must not access the network or launch unrelated external commands.
